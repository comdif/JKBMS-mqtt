Un petit script shell permettant de récupérer des données du dernier modèle JK BMS PB2A16S20P, de les transmettre via MQTT et de créer des capteurs dans Home Assistant.
Installez-le à l'emplacement de votre choix, rendez-le exécutable et configurez-le pour qu'il s'exécute en tant que tâche cron.

A small shell script that retrieves data from the latest JK BMS PB2A16S20P model, transmits it via MQTT, and creates sensors in Home Assistant.
Install it in the location of your choice, make it executable, and set it up to run as a cron job.
